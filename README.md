
# Автотрекинг целей B2B+ — тестовое задание

Материалы для отбора на проект по направлениям бизнес-аналитики (BA) и системной аналитики (SA).

## Структура репозитория

```text
src/
├── Моя_мотивация_проект_АвтотрекингЦелей.pdf
├── Тестовое_задание_BA_модуль_ККД.pdf
└── РешениеТестовогоЗадания_SA.pdf
```

## Содержание

- **Мотивация** — опыт, интерес к проекту и предполагаемая роль в команде.
- **BA** — бизнес-анализ модуля контроля качества данных (ККД): правила, метрики, процессы и критерии приёмки.
- **SA** — техническая спецификация: модель данных, ER-диаграммы, SQL, алгоритмы расчётов и контракт API.

Решения BA и SA связаны общей бизнес-логикой проекта и дополняют друг друга.
